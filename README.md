# Byaruhanga Daniel — Portfolio

Static portfolio website for the AWS Student Builder Challenge.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## AWS deployment

Deploy this repository with **AWS Amplify Hosting**. The site has no build command and the publish directory is the repository root.

## Creative feature

The “Connection Catalyst” reveal shares a personal superpower: turning meaningful conversations and new perspectives into opportunities for growth.
